User Manual

Mandate Record

Three pages, three jobs. What you must fill in, and what you can leave alone.

Amit Gupta — AI Strategy Consultant | PiP_AGI
In one line

What it does

It records the CVs you rejected, and why — not just the ones you shared. That is the only thing it does that the old form could not, and it is the whole reason it exists.

Every CV is saved the moment you tag it. There is no submit button on page two. If your laptop dies at CV sixty-three, one to sixty-two are already in.

Page one

Find the mandate

To do thisYou must fill
Find an existing mandateConsultant, plus any one other field. Partial text works — tata finds Tata Motors. All blank browses the most recent.
Create a new oneConsultant + Client name + Role title. Nothing else.
The Zoho ID is optional

Paste it if you have it. Leave it blank if you don't — the record opens either way. The Ishwa mandate ID (ISH-YYYYMM-NNNN) is created for you. Never type or invent either one.

Page two

Stage 1 filtration

Shortlisted left, Reject right. One CV at a time, on whichever side it belongs.

Per CV, on either sideRequired
Attach CVYes — one file
Candidate nameYes
Reasons (shortlisted)At least 1. No upper limit — click everything true.
Reasons (reject)At least 3 — or one hard filter on its own. Hard filters carry a small rust square.
Free textOnly if no word on offer fits.

Then press Next CV. The row saves and the panel clears.

  • Next CV won't move? Something above is missing. A message says what.
  • Word you need isn't there? Press ADD +. It goes live for everyone immediately, no approval. Write it in full — notice period too long, not NP too long.
  • No CVs to screen? Use Skip page. It writes nothing, deliberately.
Why every word is the same size

The words are meant to grow with use, so the list sorts itself to how Ishwa actually works. That sizing is calculated from real tagging, and there isn't any yet. Nothing is broken — it starts to differentiate after a few weeks of real searches.

Page three

The record

The brief, the criteria, the commercials, and what happened to each shortlisted candidate. Everyone you shortlisted on page two arrives here with the CV already attached — you never re-upload.

Per candidateRequired
Shared with clientNothing blocks you. Client outcome is asked but can wait — the client often answers weeks later. Come back and fill it in.
Held backA reason, from the same word list. Held back is not a rejection — the client never saw them.
  • You don't type CVs shared, offers made, or final CTC. They are counted from the rows. Only client shortlisted is entered by hand.
  • Save merges. A field you leave blank keeps what was stored before — so coming back months later to close the file cannot wipe the intake.
Practical

Quick answers

Do it in one sitting?No. Page two saves per CV; page three reopens as often as you like.
Edit a CV already tagged?Not in this version. Flag it and it is corrected in the sheet.
Someone else started it?Search, open, put your own name in Consultant.
Where do CVs go?One folder per mandate. Renamed to a standard pattern, with the original filename kept alongside.
Does the client see this?No. Internal to Ishwa.
When does it pay off?Around six months of ordinary use. One session is worth little; a hundred is the point.
